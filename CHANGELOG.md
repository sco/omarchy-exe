# Changelog

All notable changes to this project will be documented here.

## 1.0.1 - 2026-08-20

- Replace the exe.dev bitmap logo with an original native-QML blowfish mark.
- Refresh the marketplace preview with the new rights-clear glyph.

## 1.0.0 - 2026-08-20

- Add a keyboard-first exe.dev VM panel for the Omarchy bar.
- Browse VMs and open SSH, HTTPS, or Shelley destinations.
- Restart and create VMs through exe.dev's scoped HTTPS API.
- Store API credentials in GNOME Keyring with a configurable lifetime.
- Add refresh settings, account shortcuts, status handling, and mouse parity.
